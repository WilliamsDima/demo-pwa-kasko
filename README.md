# Осмотр авто — демо

Мобильное PWA-приложение для фотоосмотра авто перед оформлением страховки. 8 шагов съёмки через камеру браузера → отправка → результат с актом осмотра.

## Стек

- Angular 20 (standalone-компоненты)
- NgRx (store + effects) — управление состоянием
- RxJS — камера, таймер, сеть
- Своя вёрстка, без UI-библиотек

## Флоу

1. **Интро** — данные авто, чек-лист из 8 фото
2. **Съёмка** — камера, гид-рамка, таймер 15 мин, миниатюры, пересъёмка/подтверждение
3. **Отправка** — реальный HTTP-запрос с прогрессом (+имитация анализа)
4. **Результат** — скачиваемый акт осмотра, подтверждение

## Архитектура

- `src/app/core` — сервисы (камера, ориентация, сеть, отправка) + модели, общие для приложения.
- `src/app/inspection/state` — NgRx: вся бизнес-логика (actions/reducer/selectors/effects), доступ только через `InspectionFacade`.
- `src/app/inspection/pages` — smart-компоненты (роутятся, знают про стор).
- `src/app/inspection/components` — dumb-компоненты (только `@Input`/`@Output`).

`MediaStream` камеры намеренно вне NgRx (не сериализуемые данные, а браузерный объект) — живёт в `CameraService`.

Эндпоинт отправки фото задаётся в `src/environments/environment.ts` (`uploadEndpoint`) — для подключения реального бэкенда достаточно поменять значение и/или провайдер `InspectionUploadService` в `app.config.ts`.

## Ключевые решения

- Фото не обрезается — сохраняется как есть с камеры, рамка на экране — только визуальная подсказка.
- Ориентацию (портрет/landscape) для каждого фото выбирает сам пользователь; подсказка «переверните телефон» — разовая, только на первом шаге.
- В landscape управление и превью уезжают к правому краю, миниатюры — к левому (как в нативных камерах).
- PWA: service worker + манифест, ставится на экран телефона, работает офлайн. В dev-режиме (`ng serve`) специально выключено — только на проде.
- Версия сборки видна внизу интро-экрана (короткий git-хэш + время) — удобно проверять, обновился ли деплой.

## Разработка

```bash
npm install
npm start
```

Приложение будет на `http://localhost:4200`.

### Тест камеры и PWA с реального телефона

`getUserMedia` требует secure context, а service worker (без него PWA не ставится на экран) не активируется в обычном dev-режиме `ng serve`. Оба ограничения снимает:

```bash
npm run serve:lan
```

(это `ng serve --configuration production --ssl --host 0.0.0.0` — прод-конфигурация с активным service worker, HTTPS и биндом на все интерфейсы, а не только localhost).

Дальше открыть `https://<IP-компьютера>:4200` с телефона в той же Wi-Fi сети (IP смотреть через `ipconfig`, адаптер Wi-Fi). Сертификат самоподписанный — браузер попросит подтвердить исключение. После этого должна появиться возможность установить приложение на домашний экран (на Android/Chrome — баннер в приложении; на iOS/Safari — через «Поделиться → На экран «Домой»», `beforeinstallprompt` там не поддерживается).

## Сборка

```bash
npx ng build --base-href /имя-репозитория/
```

## Деплой на GitHub Pages

1. Создать репозиторий на GitHub и запушить код в ветку `main`.
2. В настройках репозитория: **Settings → Pages → Source → GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` соберёт и задеплоит приложение при каждом пуше в `main` (base-href подставляется автоматически из имени репозитория).
